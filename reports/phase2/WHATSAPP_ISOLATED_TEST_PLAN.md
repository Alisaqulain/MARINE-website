# WhatsApp Direct Cloud API: Isolated Test Plan

**Date:** 11 November 2026
**Status:** Plan. Only stage **T1** has been run (see `WHATSAPP_ISOLATED_TEST_RESULTS.md`). Every later stage needs the approvals listed against it.

## Principles

1. **Separate everything from production.**
   - A **new** Meta developer app (type Business), used only for Marina Muse testing.
   - A **test** WABA, and Meta's **test phone number** provided with the WhatsApp product on that app.
   - Never the production app (`1588276335845243`), the production WABA or the business number `917457099540`.
2. Credentials are supplied only in `.env.isolated-test.local`. They are loaded only by `scripts/isolated-env.mjs`, which blanks every value from `.env.local` and generates synthetic secrets per session.
3. Local test database only (`127.0.0.1:27018`). The app refuses non-local hosts outside production.
4. Outbound stays **forced off** (`WHATSAPP_OUTBOUND_ENABLED=false`) for T1–T4. Sending is stage T5 and needs its own written approval.
5. No secret value is printed in any log. Logs record names, fingerprints, status codes and masked IDs (`1234…5678`).
6. Every stage records start and end time, commands and results under `reports/evidence/phase2/`. Synthetic records are removed with `cleanup-synthetic-test-data.mjs`.
